# DSC — Android Application

Native Android client for Dark Skull Corporation (DSC) platform built with Kotlin and Jetpack Compose.

## Features
- **Modern Jetpack Compose UI**: Material Design 3 interface with dark cybersecurity aesthetics.
- **AI Voice & Text Assistant (Aiora)**: Integrated intelligent assistant supporting voice commands, screen context awareness, and natural language system actions.
- **Authentication & Security**: Multi-tier authentication supporting User and Admin roles with JWT verification and Bearer token interceptor.
- **Live Backend API**: Connected to DSC services for user registration, user licenses, system status, download management, and admin/owner control centers.
- **Owner Control Center & Admin Operations**: Real-time license key management, pending order processing, admin account administration, and system status controls.
- **Offline & Local Data**: Session state persistence backed by Android Jetpack DataStore Preferences.
